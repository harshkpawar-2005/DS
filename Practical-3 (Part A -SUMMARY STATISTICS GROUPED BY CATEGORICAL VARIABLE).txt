# QUESTION 1
# SUMMARY STATISTICS GROUPED BY CATEGORICAL VARIABLE

import pandas as pd
import numpy as np

data = {
    'Name' : ['A', 'B', 'C', 'D', 'E',
              'F', 'G', 'H', 'I', 'J'],

    'Age_Group' : ['Young', 'Young', 'Adult',
                   'Adult', 'Senior',
                   'Young', 'Adult',
                   'Senior', 'Senior',
                   'Young'],

    'Income' : [25000, 27000, 40000,
                42000, 50000,
                26000, 41000,
                52000, 51000,
                28000]
}

df = pd.DataFrame(data)

print("\nEmployee Dataset")
print(df)

grouped_data = df.groupby('Age_Group')

print("\nSummary Statistics of Income Grouped by Age_Group")

print(grouped_data['Income'].agg([
    'mean',
    'median',
    'min',
    'max',
    'std'
]))

young = list(
    df[df['Age_Group'] == 'Young']
    ['Income']
)

adult = list(
    df[df['Age_Group'] == 'Adult']
    ['Income']
)

senior = list(
    df[df['Age_Group'] == 'Senior']
    ['Income']
)

print("\nIncome List for Young")
print(young)

print("\nIncome List for Adult")
print(adult)

print("\nIncome List for Senior")
print(senior)

5. VIVA PART

1. What is Statistics in Data Science?

Answer:
Statistics is the science of collecting, analyzing, and interpreting data.

In Data Science, it helps to:
- Understand data patterns
- Summarize data
- Make decisions

It is the foundation for machine learning and data analysis.



2. What is Mean?

Answer:
Mean is the average value of a dataset.

Formula:

Mean = ∑X / N

It represents the central value but is affected by outliers.



3. What is Median?

Answer:
Median is the middle value when data is arranged in order.

- If odd → middle value
- If even → average of two middle values

It is not affected by outliers, so it is more reliable in skewed data.



4. What is Mode?

Answer:
Mode is the most frequently occurring value in a dataset.

Used for:
- Categorical data
- Identifying most common values



5. Difference between Mean, Median, Mode

Mean
- Average
- Affected by outliers
- Used for numeric data

Median
- Middle value
- Not affected by outliers
- Used for numeric data

Mode
- Most frequent value
- Not affected by outliers
- Used for categorical data also



6. What is Variance?

Answer:
Variance measures how much data values spread from the mean.

- High variance → data widely spread
- Low variance → data close to mean



7. What is Standard Deviation?

Answer:
Standard deviation is the square root of variance.

It tells:
How much data deviates from the mean.

- Low SD → stable data
- High SD → more variation



8. What is Data Visualization?

Answer:
Data visualization is the graphical representation of data.

It helps to:
- Understand patterns
- Detect trends
- Identify outliers

Examples:
- Bar chart
- Histogram
- Pie chart



9. What is a Histogram?

Answer:
Histogram shows the distribution of numerical data.

- Data divided into bins
- Frequency is shown

Used to understand:
- Shape of data
- Skewness



10. What is a Bar Chart?

Answer:
Bar chart is used to compare categorical data.

- X-axis → categories
- Y-axis → values

Example:
Sales of different products.



11. What is a Pie Chart?

Answer:
Pie chart shows proportions or percentages.

- Circle divided into parts
- Each part represents a category



12. What is a Boxplot?

Answer:
Boxplot shows:
- Median
- Quartiles
- Outliers

Used for:
- Detecting outliers
- Understanding distribution



13. What is Correlation?

Answer:
Correlation shows the relationship between two variables.

- +1 → strong positive correlation
- -1 → strong negative correlation
- 0 → no relation



14. What is Scatter Plot?

Answer:
Scatter plot shows relationship between two variables.

- Each point represents a data value
- Helps identify correlation



15. What is the use of visualization in Data Science?

Answer:
Visualization helps:
- Easy understanding of data
- Detect hidden patterns
- Communicate insights clearly
