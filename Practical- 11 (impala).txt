1. CODE

import sqlite3

# ---------------------------------------------------
# Connect to Database
# ---------------------------------------------------

conn = sqlite3.connect("student.db")

cursor = conn.cursor()

print("Database Connected Successfully")


# ---------------------------------------------------
# Create Table
# ---------------------------------------------------

cursor.execute("""
CREATE TABLE IF NOT EXISTS students (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER,
    marks INTEGER
)
""")

print("Table Created Successfully")


# ---------------------------------------------------
# Insert Data
# ---------------------------------------------------

cursor.execute("INSERT INTO students VALUES (1, 'Abhinav', 20, 85)")
cursor.execute("INSERT INTO students VALUES (2, 'Rahul', 21, 78)")
cursor.execute("INSERT INTO students VALUES (3, 'Sneha', 19, 92)")

conn.commit()

print("Data Inserted Successfully")


# ---------------------------------------------------
# Display All Records
# ---------------------------------------------------

print("\nALL STUDENTS:\n")

cursor.execute("SELECT * FROM students")

rows = cursor.fetchall()

for row in rows:
    print(row)


# ---------------------------------------------------
# Students with Marks > 80
# ---------------------------------------------------

print("\nSTUDENTS WITH MARKS > 80:\n")

cursor.execute("""
SELECT * FROM students
WHERE marks > 80
""")

for row in cursor.fetchall():
    print(row)


# ---------------------------------------------------
# Average Marks
# ---------------------------------------------------

print("\nAVERAGE MARKS:\n")

cursor.execute("""
SELECT AVG(marks) FROM students
""")

print(cursor.fetchone())


# ---------------------------------------------------
# Update Marks
# ---------------------------------------------------

cursor.execute("""
UPDATE students
SET marks = 88
WHERE id = 2
""")

conn.commit()

print("\nMARKS UPDATED")


# ---------------------------------------------------
# Delete Record
# ---------------------------------------------------

cursor.execute("""
DELETE FROM students
WHERE id = 1
""")

conn.commit()

print("RECORD DELETED")


# ---------------------------------------------------
# Final Table
# ---------------------------------------------------

print("\nFINAL TABLE:\n")

cursor.execute("SELECT * FROM students")

for row in cursor.fetchall():
    print(row)


# ---------------------------------------------------
# Close Connection
# ---------------------------------------------------

conn.close()

print("\nConnection Closed")


2. EXPLANATION OF CODE LINE BY LINE

import sqlite3

This line imports the sqlite3 module in Python.

SQLite is a lightweight database system that stores data in a file.

The sqlite3 module allows Python programs to:

Create databases

Create tables

Insert records

Update records

Delete records

Execute SQL queries

It is a built-in library, so no installation is required.


# ---------------------------------------------------
# Connect to Database
# ---------------------------------------------------

These comment lines are used only for readability and section separation.

They help organize the program into different logical parts.


conn = sqlite3.connect("student.db")

This line creates a connection with the SQLite database.

If the database file student.db already exists:

Python connects to it.

If the database does not exist:

SQLite automatically creates it.

The connection object is stored inside variable conn.

This connection is required to perform database operations.


cursor = conn.cursor()

A cursor object is created using the connection.

Cursor is used to execute SQL commands such as:

CREATE TABLE

INSERT

SELECT

UPDATE

DELETE

Without cursor, SQL queries cannot be executed.


print("Database Connected Successfully")

This line prints a success message indicating that the database connection has been established successfully.


# ---------------------------------------------------
# Create Table
# ---------------------------------------------------

These comments separate the table creation section from the rest of the program.


cursor.execute("""

The execute() function is used to execute SQL commands.

Triple quotes """ are used for writing multi-line SQL queries.


CREATE TABLE IF NOT EXISTS students (

This SQL command creates a table named students.

IF NOT EXISTS means:

If the table already exists, SQLite will not create it again.

This prevents errors from occurring.


id INTEGER PRIMARY KEY,

This creates a column named id.

INTEGER means only integer values are allowed.

PRIMARY KEY means:

Every record must have a unique id.

This column uniquely identifies each student.


name TEXT,

This creates a column named name.

TEXT datatype stores character/string values.


age INTEGER,

This creates a column named age.

INTEGER datatype stores numeric integer values.


marks INTEGER

This creates a column named marks.

It stores students' marks as integer values.


)
""")

This completes and executes the SQL query for table creation.


print("Table Created Successfully")

Displays a message confirming successful table creation.


# ---------------------------------------------------
# Insert Data
# ---------------------------------------------------

These comments indicate the beginning of data insertion section.


cursor.execute("INSERT INTO students VALUES (1, 'Abhinav', 20, 85)")

This SQL query inserts one row into the students table.

Inserted values are:

ID = 1

Name = Abhinav

Age = 20

Marks = 85


cursor.execute("INSERT INTO students VALUES (2, 'Rahul', 21, 78)")

This inserts the second student record into the table.


cursor.execute("INSERT INTO students VALUES (3, 'Sneha', 19, 92)")

This inserts the third student record into the table.


conn.commit()

commit() permanently saves all changes made to the database.

Without commit():

Inserted data will not be saved permanently.


print("Data Inserted Successfully")

Displays a success message after insertion.


# ---------------------------------------------------
# Display All Records
# ---------------------------------------------------

These comments indicate the section for displaying records.


print("\nALL STUDENTS:\n")

This prints the heading ALL STUDENTS.

\n creates a new line for better formatting.


cursor.execute("SELECT * FROM students")

This SQL query selects all records from the students table.

SELECT * means:

Select every column from the table.


rows = cursor.fetchall()

fetchall() retrieves all records returned by the SELECT query.

All rows are stored inside variable rows as a list.


for row in rows:

This loop iterates through every row in the result set.


print(row)

Prints each row one by one.


# ---------------------------------------------------
# Students with Marks > 80
# ---------------------------------------------------

These comments indicate filtering records based on condition.


print("\nSTUDENTS WITH MARKS > 80:\n")

Prints a heading before displaying filtered records.


cursor.execute("""

Starts another SQL query.


SELECT * FROM students

Selects all columns from students table.


WHERE marks > 80

WHERE clause filters only those students whose marks are greater than 80.


""")

Executes the filtering query.


for row in cursor.fetchall():

fetchall() retrieves filtered records.

Loop iterates through each matching row.


print(row)

Prints each filtered student record.


# ---------------------------------------------------
# Average Marks
# ---------------------------------------------------

These comments indicate average calculation section.


print("\nAVERAGE MARKS:\n")

Prints heading for average marks output.


cursor.execute("""

Starts SQL query for average calculation.


SELECT AVG(marks) FROM students

AVG() is an SQL aggregate function.

It calculates the average of marks column.


""")

Executes the SQL query.


print(cursor.fetchone())

fetchone() retrieves only one result row.

Since AVG() returns a single value, fetchone() is used.


# ---------------------------------------------------
# Update Marks
# ---------------------------------------------------

These comments indicate record update section.


cursor.execute("""

Starts SQL UPDATE query.


UPDATE students

UPDATE command modifies existing records.


SET marks = 88

Changes marks value to 88.


WHERE id = 2

Only the student with ID 2 will be updated.


""")

Executes the update query.


conn.commit()

Saves updated changes permanently into the database.


print("\nMARKS UPDATED")

Displays success message after updating marks.


# ---------------------------------------------------
# Delete Record
# ---------------------------------------------------

These comments indicate delete operation section.


cursor.execute("""

Starts DELETE SQL query.


DELETE FROM students

DELETE command removes records from table.


WHERE id = 1

Deletes only the student whose ID is 1.


""")

Executes the delete query.


conn.commit()

Saves deletion permanently into database.


print("RECORD DELETED")

Displays success message after deleting record.


# ---------------------------------------------------
# Final Table
# ---------------------------------------------------

These comments indicate the section for displaying final updated table.


print("\nFINAL TABLE:\n")

Prints heading for final table output.


cursor.execute("SELECT * FROM students")

Again selects all remaining records from the table.


for row in cursor.fetchall():

Retrieves all remaining rows and iterates through them.


print(row)

Prints each remaining row after update and delete operations.


# ---------------------------------------------------
# Close Connection
# ---------------------------------------------------

These comments indicate database closing section.


conn.close()

This closes the database connection.

Closing connection is important because:

It releases memory

Prevents resource leakage

Ensures proper database handling


print("\nConnection Closed")

Displays message confirming database connection has been closed successfully.
