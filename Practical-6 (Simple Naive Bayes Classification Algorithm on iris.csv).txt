1. CODE

import pandas as pd
import numpy as np

from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler
from sklearn.naive_bayes import GaussianNB

from sklearn.metrics import (
    confusion_matrix,
    accuracy_score,
    precision_score,
    recall_score
)

iris = load_iris()

df = pd.DataFrame(
    iris.data,
    columns=iris.feature_names
)

df['Species'] = pd.Categorical.from_codes(
    iris.target,
    iris.target_names
)

print("\n========== IRIS DATASET ==========\n")
print(df.to_string())

print("\n========== NULL VALUES ==========\n")
print(df.isnull().sum())

X = iris.data

y = iris.target

X_train, X_test, y_train, y_test = train_test_split(
    X,
    y,
    test_size=0.3,
    random_state=1
)

sc = StandardScaler()

X_train = sc.fit_transform(X_train)
X_test = sc.transform(X_test)

gaussian = GaussianNB()

gaussian.fit(X_train, y_train)

y_pred = gaussian.predict(X_test)

print("\n========== PREDICTED VALUES ==========\n")
print(y_pred)

cm = confusion_matrix(y_test, y_pred)

print("\n========== CONFUSION MATRIX ==========\n")
print(cm)

accuracy = accuracy_score(y_test, y_pred)
print("\nAccuracy :", accuracy)

error_rate = 1 - accuracy
print("Error Rate :", error_rate)

precision = precision_score(y_test, y_pred, average='micro')
print("Precision :", precision)

recall = recall_score(y_test, y_pred, average='micro')
print("Recall :", recall)

print("\n========== TP, FP, TN, FN ==========\n")

for i in range(len(cm)):

    TP = cm[i, i]

    FP = cm[:, i].sum() - TP

    FN = cm[i, :].sum() - TP

    TN = cm.sum() - (TP + FP + FN)

    print("Class", i)
    print("TP =", TP)
    print("FP =", FP)
    print("FN =", FN)
    print("TN =", TN)
    print()

1. What is Naïve Bayes Algorithm?

Answer:
Naïve Bayes is a supervised machine learning classification algorithm based on Bayes Theorem.

It is mainly used for:
- Classification problems
- Predicting categorical outputs

It assumes that all input features are independent of each other.

Examples:
- Spam detection
- Disease prediction
- Text classification



2. Why is it called “Naïve” Bayes?

Answer:
It is called “Naïve” because the algorithm assumes that all features are independent from each other, which is a very simple or naïve assumption.

For example:
Sepal length and petal length are assumed independent in Iris dataset.

Even though this assumption may not be true, the algorithm works well in many cases.

6. What is Bayes Theorem?

Answer:
Bayes Theorem is a probability formula used to find conditional probability.

Formula:

P(A|B) =
[P(B|A) × P(A)] / P(B)

Where:
- P(A|B) = probability of A given B
- P(B|A) = probability of B given A
- P(A) = prior probability
- P(B) = evidence probability

Naïve Bayes uses this theorem for classification.



7. What is prior probability?

Answer:
Prior probability is the probability of an event before considering any additional information.

Example:
P(A)

It represents initial belief about an event.



8. What is conditional probability?

Answer:
Conditional probability is the probability of an event occurring given that another event has already occurred.

Formula:
P(A|B)

It means probability of A when B is true.

21. What is True Positive (TP)?

Answer:
True Positive means:
- Actual class is positive
- Predicted class is also positive

Correct positive prediction.



22. What is True Negative (TN)?

Answer:
True Negative means:
- Actual class is negative
- Predicted class is also negative

Correct negative prediction.



23. What is False Positive (FP)?

Answer:
False Positive means:
- Actual class is negative
- Predicted class is positive

Wrong positive prediction.

Also called Type-1 Error.



24. What is False Negative (FN)?

Answer:
False Negative means:
- Actual class is positive
- Predicted class is negative

Wrong negative prediction.

Also called Type-2 Error.



25. What is Accuracy?

Answer:
Accuracy measures how many predictions are correct.

Formula:

Accuracy =
(TP + TN) /
(TP + TN + FP + FN)

Higher accuracy means better model performance.



26. What is Precision?

Answer:
Precision measures how many predicted positive values are actually positive.

Formula:

Precision =
TP / (TP + FP)

High precision means fewer false positives.



27. What is Recall?

Answer:
Recall measures how many actual positive cases are correctly predicted.

Formula:

Recall =
TP / (TP + FN)

High recall means fewer false negatives.



28. What is Error Rate?

Answer:
Error Rate measures incorrect predictions.

Formula:

Error Rate =
(FP + FN) / Total

Lower error rate indicates better model performance.
