import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error, r2_score

data = pd.read_csv("Boston Housing Data.xls")

print("\nBoston Housing Dataset")
print(data)

print("\nFirst 5 Rows")
print(data.head())

print("\nMissing Values")
print(data.isnull().sum())

data = data.fillna(data.mean())

x = data.drop(['MEDV'], axis=1)

y = data['MEDV']

xtrain, xtest, ytrain, ytest = train_test_split(
    x,
    y,
    test_size=0.2,
    random_state=0
)

lm = LinearRegression()

model = lm.fit(xtrain, ytrain)

ytrain_pred = lm.predict(xtrain)

ytest_pred = lm.predict(xtest)

print("\nPredicted Values for Training Data")
print(ytrain_pred)

print("\nPredicted Values for Testing Data")
print(ytest_pred)

mse_train = mean_squared_error(ytrain, ytrain_pred)

mse_test = mean_squared_error(ytest, ytest_pred)

print("\nMean Squared Error for Training Data")
print(mse_train)

print("\nMean Squared Error for Testing Data")
print(mse_test)

r2 = r2_score(ytest, ytest_pred)

print("\nR-Squared Value")
print(r2)

plt.scatter(
    ytrain,
    ytrain_pred,
    c='blue',
    marker='o',
    label='Training Data'
)

plt.scatter(
    ytest,
    ytest_pred,
    c='green',
    marker='s',
    label='Testing Data'
)

plt.xlabel("True Values")

plt.ylabel("Predicted Values")

plt.title("True Values vs Predicted Values")

plt.legend(loc='upper left')

plt.show()

5. VIVA PART

1. What is Probability?

Answer:
Probability tells us how likely an event is to happen.

Its value lies between 0 and 1:
- 0 → impossible event
- 1 → certain event

Example:
Probability of getting head in coin toss = 1/2

It helps in making predictions under uncertainty.



2. What is a Random Variable?

Answer:
A random variable is a variable whose value depends on the outcome of a random experiment.

Types:
- Discrete → countable (e.g., number of students)
- Continuous → measurable (e.g., height, weight)

It converts real-world outcomes into numerical form for analysis.



3. What is a Probability Distribution?

Answer:
A probability distribution shows all possible values of a random variable and their probabilities.

It helps us understand:
- Which outcomes are likely
- How data is spread

Example:
Distribution of marks of students.



4. What is Normal Distribution?

Answer:
Normal distribution is a bell-shaped, symmetrical curve.

Key properties:
- Mean = Median = Mode
- Data is evenly distributed around mean
- Most values lie near the center

It is widely used because many real-world data follow this pattern.



5. What is Standard Deviation?

Answer:
Standard deviation measures how much data values deviate from the mean.

- Low SD → values close to mean
- High SD → values widely spread

It helps in understanding variability of data.



6. Explain the 68–95–99 Rule

Answer:
In normal distribution:
- 68% data lies within 1 standard deviation
- 95% within 2 standard deviations
- 99.7% within 3 standard deviations

This rule helps estimate data spread quickly.



7. What is Hypothesis Testing?

Answer:
Hypothesis testing is a statistical method used to make decisions using data.

We test an assumption and decide whether it is true or false.

It is widely used in research and machine learning.



8. What is Null Hypothesis (H₀)?

Answer:
Null hypothesis means no effect or no difference.

Example:
“There is no difference between two teaching methods”

It is the assumption we try to test.



9. What is Alternative Hypothesis (H₁)?

Answer:
Alternative hypothesis means there is an effect or difference.

Example:
“There is a difference between two methods”

It is accepted when null hypothesis is rejected.



10. What is p-value?

Answer:
p-value tells us how strong the evidence is against the null hypothesis.

- p < 0.05 → reject H₀
- p > 0.05 → do not reject H₀

Smaller p-value = stronger evidence.



11. What is Significance Level (α)?

Answer:
Significance level is a threshold used to decide whether to reject H₀.

Common value:
0.05 (5%)

It defines the risk of making an incorrect decision.



12. What is Z-test?

Answer:
Z-test is used when:
- Sample size is large
- Population standard deviation is known

It checks whether sample mean differs from population mean.



13. What is T-test?

Answer:
T-test is used when:
- Sample size is small
- Standard deviation is unknown

It is more practical for real-world data.



14. Difference between Z-test and T-test

Z-test
- Large sample size
- SD known
- Uses normal distribution

T-test
- Small sample size
- SD unknown
- Uses t-distribution



15. What is Type I Error?

Answer:
Type I error occurs when we reject a true null hypothesis.

Also called false positive.

Example:
Saying a medicine works when it actually doesn’t.



16. What is Type II Error?

Answer:
Type II error occurs when we accept a false null hypothesis.

Also called false negative.

Example:
Saying a medicine doesn’t work when it actually does.



17. Why is Hypothesis Testing important?

Answer:
It helps to:
- Make scientific decisions
- Validate assumptions
- Compare results
- Reduce guesswork

It provides a logical way to analyze data.
