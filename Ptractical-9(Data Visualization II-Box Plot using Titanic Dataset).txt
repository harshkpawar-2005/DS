import seaborn as sns

import pandas as pd

    y='age',
    hue='survived',

plt.ylabel("Age")

========================================================

UNDERSTANDING BOX PLOT

A Box Plot contains:

1. Median
• Middle line inside box.
• Represents middle age value.

2. Quartiles
• Q1 → 25% data
• Q2 → Median
• Q3 → 75% data

3. IQR

IQR = Q3 - Q1

• Represents middle 50% data spread.

4. Whiskers
• Show data range excluding outliers.

5. Outliers
• Dots outside whiskers.
• Represent abnormal values.

5. What are quartiles in Box Plot?
Answer:

Quartiles divide data into four equal parts:

• Q1 (First Quartile) → 25% data
• Q2 (Median) → 50% data
• Q3 (Third Quartile) → 75% data

6. What does the line inside the box represent?
Answer:

--------------------------------------------------------

7. What is IQR?
Answer:
IQR stands for Interquartile Range.

Formula:

IQR = Q3 − Q1

It represents the spread of middle 50% data.

--------------------------------------------------------

8. What are whiskers in Box Plot?
Answer:
Whiskers represent the range of data excluding outliers.

They extend from:
• Minimum value to Q1
• Q3 to Maximum value

--------------------------------------------------------

9. What are outliers?
Answer:
Outliers are unusual data points that are far away from the normal data range.

In box plots, outliers are shown using:
• Dots
