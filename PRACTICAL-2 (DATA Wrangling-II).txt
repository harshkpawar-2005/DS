5. VIVA PART

1. What are Null/Missing Values?

Answer:
Null values are data points that are missing or not recorded in the dataset.

They are represented as:
- NaN (Not a Number)
- None

They can occur due to:
- Data entry errors
- System failures
- Incomplete data collection

Handling them is important because they can affect analysis and model performance.



2. How do you handle missing values?

Answer:
There are mainly two ways:

1. Remove data
- dropna() → removes rows/columns with missing values
- Used when missing data is very small

2. Fill data
- fillna() → replaces missing values

Methods:
- Mean (for numerical data)
- Median
- Mode (for categorical data)

Choice depends on dataset and context.



3. What is an Outlier?

Answer:
An outlier is a data point that is significantly different from other values.

Example:
If most salaries are between 20k–50k and one is 5 lakh → that is an outlier.

Outliers can:
- Skew results
- Affect mean and standard deviation
- Reduce model accuracy

ADDITIONAL VIVA QUESTIONS & ANSWERS



4. How do you detect outliers?

Answer:
Common methods:

1. Boxplot
- Visual method
- Shows median, quartiles, and outliers

2. Z-score
- Statistical method

Formula:

Z = (X − μ) / σ

If Z > 3 or Z < -3 → outlier



5. What is a Boxplot?

Answer:
A boxplot is a graphical representation used to detect distribution and outliers.

It contains:
- Minimum
- First quartile (Q1)
- Median
- Third quartile (Q3)
- Maximum

Points outside whiskers are considered outliers.



6. What is Z-score?

Answer:
Z-score measures how far a value is from the mean in terms of standard deviations.

- Z = 0 → value equals mean
- Z > 0 → above mean
- Z < 0 → below mean

Used for:
- Outlier detection
- Standardization



7. What is Data Transformation?

Answer:
Data transformation means converting data into a suitable format or scale.

Examples:
- Log transformation
- Square root transformation
- Scaling

Purpose:
- Reduce skewness
- Improve model performance
- Normalize distribution



8. What is Skewness?

Answer:
Skewness refers to the asymmetry of data distribution.

Types:

1. Positive Skew
- Tail on right side

2. Negative Skew
- Tail on left side

3. Zero Skew
- Symmetrical data

Skewed data may affect machine learning models.



9. How do you reduce skewness?

Answer:
We use transformations like:
- Log transformation
- Square root transformation
- Box-Cox transformation

These help make data more normally distributed.



10. Difference between dropna() and fillna()

Answer:

dropna()
- Removes missing values
- May reduce dataset size
- Used when few null values

fillna()
- Replaces missing values
- Keeps dataset size same
- Used when many null values



11. Why is outlier treatment important?

Answer:
Outliers can:
- Distort statistical measures (mean, variance)
- Mislead models
- Reduce prediction accuracy

Handling them improves:
- Model performance
- Data reliability



12. What happens if you ignore missing values?

Answer:
- Model may crash
- Incorrect predictions
- Biased results
- Reduced accuracy



13. What is IQR (Interquartile Range)?

Answer:
IQR = Q3 − Q1

Used to detect outliers:

Lower bound = Q1 − 1.5 × IQR

Upper bound = Q3 + 1.5 × IQR

Values outside this range are outliers.
