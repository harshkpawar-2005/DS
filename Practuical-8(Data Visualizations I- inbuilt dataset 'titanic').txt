import seaborn as sns
import matplotlib.pyplot as plt
import pandas as pd

titanic = sns.load_dataset('titanic')

print(titanic.to_string())

print("\n========== DATASET INFORMATION ==========\n")

print(titanic.info())

print("\n========== DATASET SHAPE ==========\n")

print(titanic.shape)

print("\n========== MISSING VALUES ==========\n")

print(titanic.isnull().sum())

plt.figure(figsize=(6,5))

sns.countplot(
    x='survived',
    data=titanic
)

plt.title("Survival Count")

plt.xlabel("Survived (0 = No, 1 = Yes)")
plt.ylabel("Number of Passengers")

plt.show()

plt.figure(figsize=(6,5))

sns.countplot(
    x='sex',
    hue='survived',
    data=titanic
)

plt.title("Survival Based on Gender")

plt.xlabel("Gender")
plt.ylabel("Count")

plt.show()

plt.figure(figsize=(6,5))

sns.countplot(
    x='pclass',
    data=titanic
)

plt.title("Passenger Class Distribution")

plt.xlabel("Passenger Class")
plt.ylabel("Count")

plt.show()

plt.figure(figsize=(8,5))

sns.histplot(
    titanic['age'].dropna(),
    bins=30,
    kde=False
)

plt.title("Age Distribution of Passengers")

plt.xlabel("Age")
plt.ylabel("Frequency")

plt.show()

plt.figure(figsize=(8,5))

sns.boxplot(
    x='sex',
    y='age',
    data=titanic
)

plt.title("Box Plot of Age vs Gender")

plt.xlabel("Gender")
plt.ylabel("Age")

plt.show()

plt.figure(figsize=(8,5))

sns.histplot(
    titanic['fare'].dropna(),
    bins=30,
    kde=False
)

plt.title("Fare Distribution of Titanic Passengers")

plt.xlabel("Fare")
plt.ylabel("Number of Passengers")

plt.show()

3. What is Seaborn?

It provides:

Attractive plots

Statistical visualizations

Easy-to-use functions

Import statement:

import seaborn as sns


4. Why is Seaborn used?

Supports statistical plots

Works well with Pandas dataframes

7. What are distribution plots?
Answer:
Distribution plots help visualize how data values are distributed.

They help understand:

Mean

Median

Variance

Frequency

Examples:

Distplot

Jointplot

Rugplot



8. What is Distplot?
Answer:
Distplot displays the distribution of a continuous variable using a histogram.

Example:

sns.distplot(dataset['age'])

It helps analyze frequency distribution.



9. What is KDE in Distplot?
Answer:
KDE stands for Kernel Density Estimation.

It displays a smooth probability density curve over the histogram.

To remove KDE:

sns.distplot(dataset['age'], kde=False)

10. What is Joint Plot?
Answer:
Joint Plot combines:

Two distribution plots

One scatter plot

It helps analyze relationship between two variables.

Example:

sns.jointplot(x='age', y='fare', data=dataset)


11. What is Hex Plot in Joint Plot?
Answer:
Hex plot displays data using hexagonal bins.

Darker hexagons indicate:

Higher number of observations

Example:

kind='hex'

12. What is Rug Plot?
Answer:
Rug Plot draws small vertical lines for each data point along the axis.

Example:

sns.rugplot(dataset['fare'])

It helps visualize data density.



13. What are categorical plots?
Answer:
Categorical plots visualize categorical data against numeric or categorical variables.

Examples:

Bar plot

Count plot

Box plot

Violin plot



14. What is a Bar Plot?
Answer:
Bar plot displays aggregate values like:

Mean

Sum

Standard deviation

Example:

sns.barplot(x='sex', y='age', data=dataset)


15. What is Count Plot?
Answer:
Count plot shows the number of observations in each category.

Example:

sns.countplot(x='sex', data=dataset)

It counts male and female passengers.



16. What is a Box Plot?
Answer:
Box plot shows data distribution using quartiles.

It displays:

Median

Quartiles

Outliers

Example:

sns.boxplot(x='sex', y='age', data=dataset)


17. What are outliers in Box Plot?
Answer:
Outliers are abnormal data points that lie far away from normal values.

In box plots, outliers are shown using dots.

18. What is Violin Plot?
Answer:
Violin plot combines:

Box plot

Density plot

It shows complete data distribution.

Example:

sns.violinplot(x='sex', y='age', data=dataset)


19. What is the advantage of Violin Plot over Box Plot?
Answer:
Violin plot provides more detailed distribution information than box plot.

It shows:

Density of data

Shape of distribution

20. Which parameter adds another categorical variable in violin plot?
Answer:
The hue parameter is used.

Example:

sns.violinplot(x='sex', y='age', data=dataset, hue='survived')


21. What is Strip Plot?
Answer:
Strip plot displays scatter points for categorical data.

Example:

sns.stripplot(x='sex', y='age', data=dataset)


22. What is jitter in Strip Plot?
Answer:
Jitter adds random noise to avoid overlapping points.

Example:

jitter=True

This improves visualization.

23. What is Swarm Plot?
Answer:
Swarm plot is similar to strip plot but avoids overlapping points.

Example:

sns.swarmplot(x='sex', y='age', data=dataset)


24. What is Heat Map?
Answer:
Heat map displays correlation values using colors in matrix form.

Example:

sns.heatmap(corr)

Higher correlation is shown using lighter colors.



25. What is correlation?
Answer:
Correlation measures relationship between two variables.

Values range from:

-1 to +1

Interpretation:

+1 → strong positive relation

-1 → strong negative relation

0 → no relation

26. What is corr() function?
Answer:
corr() calculates correlation between numeric columns.

Example:

dataset.corr()

27. What is annot=True in Heatmap?
Answer:
annot=True displays correlation values inside heatmap cells.

Example:

sns.heatmap(corr, annot=True)

28. What is Cluster Map?
Answer:
Cluster map groups similar rows and columns using hierarchical clustering.

It helps identify similar patterns in data.

29. Why is histogram used for fare column?
Answer:
Histogram is used to visualize distribution of ticket fare values.

Example:

sns.histplot(dataset['fare'], bins=10)

It shows frequency of passengers for different fare ranges.
